Where your data lives

Keep it as a file in a folder you choose. Put that folder inside OneDrive, Google Drive, Dropbox or any folder that already syncs, and your history survives a new Windows or a new computer — point the app at the same folder again and everything is back.

Desktop widget

Ctrl+Shift+D hides and brings back the widget, and so does the icon by the clock.

Pinned, it leaves the taskbar and Alt+Tab, stays behind whatever you are working in rather than over it, and comes back after “show desktop”. Windows has no real way to fasten a window to the wallpaper, so this is as close as it gets without machinery this app does not otherwise need.
